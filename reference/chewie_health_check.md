# Check the status of {chewie}

checks the NASA Earthdata Credentials and GEDI Cache environment
variables

## Usage

``` r
chewie_health_check(.test = TRUE, .report_cache = TRUE)
```

## Arguments

- .test:

  logical; whether to test the credentials (requires internet
  connection)

- .report_cache:

  logical; whether to report the cache status (default: TRUE)
