# plot a `chewie.find` object

`plot.chewie.find` is a method for plotting `chewie.find` objects.

## Usage

``` r
# S3 method for class 'chewie.find'
plot(x, swath_col = "#903ca586", aoi_col = "#cecece", ...)
```

## Arguments

- x:

  chewie.find object to print

- swath_col:

  character; color of the granules.

- aoi_col:

  character; color of the aoi.

- ...:

  arguments passed to `print.sf`

## Value

a base R plot.
